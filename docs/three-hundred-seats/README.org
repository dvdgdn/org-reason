#+title: Three Hundred Seats — build your own trusted system
#+startup: showall
#+options: toc:nil num:nil

/Three Hundred Seats/ is a novella in which Maya Torres loses a sold-out
benefit's hall ten days before the event and learns, one promise at a time,
the practice David Allen calls Getting Things Done. The whole novella is here,
one chapter to a page, and each chapter is followed by an exercise. By chapter
17 you have a working system of your own, built from your own commitments.

* How each page works

Every page has the same five parts.

- *The chapter* :: the story itself.
- *What Maya has just learned* :: the chapter's lesson in a few lines. It gives
  away nothing from later chapters.
- *Your trusted system — Step N* :: the exercise in general terms. It works
  with paper, a notes app, or anything else. This is the part printed at the end
  of the chapter.
- *The same step in Org Reason* :: the same exercise with Org Reason's commands,
  on your real records.
- *Carry forward* :: what to keep for the next step.

Each step uses what the earlier steps produced, so do them in order. Most take
five minutes. Step 2 and step 11 take fifteen.

The story is in four parts: Losing the Hall (chapters 1–4), Saving the Seats
(5–9), Changing the Promise (10–13) and Keeping the Promise (14–17). The
[[file:appendix.org][appendix]] shows how the story was built and sums up the method. Read it last.

* What you have at the end

One system, in five parts that Allen names capture, clarify, organize, reflect
and engage:

- one inbox that everything goes into (steps 1–2);
- a Next Actions list, a Projects list, a Waiting For list, a calendar, a list
  per person and a Someday list (steps 3–10);
- a review that keeps them true (steps 11–15);
- and the habit of choosing from them and adding to them as you go (steps 16–17).

* Before you start with Org Reason

You need Org Reason installed and =org-reason-mode= on (see [[file:../install.md][install.md]]). The
keys below assume the default prefix, ~C-c r~; ~C-c r ?~ shows the menu.

These exercises use your real workspace, because the point is a system that
holds your real commitments. If you would rather learn the keys on invented
data first, ~C-c r h~ opens the [[file:../user-guide.org][tutorial]] in a separate Emacs. The decisions
behind each command are explained in [[file:../gtd.md][gtd.md]].

Org Reason sends no messages and sets no alarms. When a step says to tell
someone or to be reminded, you send the message yourself, and the reminder is
an entry you will see in the agenda (~C-c r a~).
